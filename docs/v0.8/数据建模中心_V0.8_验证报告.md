## 风险与使用限制

1. 外键目标字段必须具备适用的唯一性，生成器当前只提供必要验证/风险提示，真实引擎仍可能拒绝 DDL。
2. CHECK 表达式使用有限 tokenizer，不是完整 SQL AST / parser；复杂表达式必须在目标引擎测试。
3. Hive 约束可能只是逻辑元数据，不等于运行时强制约束。
4. `/metrics` 仍为轻量进程内实现，不适用于多 worker 汇总或生产告警。
5. 应用拒绝 production/staging，认证头仍属于演示机制。
