## 已验证但不代表生产就绪

- 以上真实执行的数据库迁移测试均基于隔离 SQLite。
- 未在真实 PostgreSQL 服务运行 migration、并发/锁测试和备份恢复验证。
- PostgreSQL / MySQL / Hive DDL 仍是字符串预览，未对真实版本执行。
- 浏览器端端到端自动化尚未通过正式验收；本版以 API 集成测试、JavaScript 语法检查和 DOM ID 静态检查为主。
- 生产级 OIDC/SSO、资源级 RBAC/ABAC、外部指标/日志/Trace/告警、性能/渗透测试、高可用和容灾尚未完成。

## 重要设计限制

- 需求状态当前允许通用 PUT 更新，尚无严格的状态转换动作和已确认需求冻结机制。
- `model_relationships` 尚未纳入 `model_versions.snapshot_json`；当前 diff 不包含关系边变化。
- 模型关系的同项目校验在 API 层执行，数据库层尚未使用复合外键强制项目 ID 一致。
- 字段批量粘贴支持固定列顺序 TSV，不等同于完整 CSV 导入器。
- 应用继续拒绝 `APP_ENV=production` / `staging` 启动。
